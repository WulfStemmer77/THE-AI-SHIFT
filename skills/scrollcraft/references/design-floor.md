# Design floor

## Typography
- Two font families maximum unless the brand system requires more.
- Tighten tracking as display size increases.
- Keep reading measure roughly 45–75 characters per line.
- Use line-height inversely with measure and size.
- Do not use light font weights over busy media without testing legibility.

## Spacing
- Use a base spacing scale, not arbitrary gaps.
- More space above a new thought than below its heading.
- Use fluid section spacing so mobile does not inherit desktop emptiness.

## Color
Define functional roles:
- canvas
- surface
- primary ink
- secondary ink
- accent
- accent ink

Avoid pure black when a deep neutral produces better depth. Secondary text should belong to the palette, not default to flat gray.

## Depth
Use a mix of:
- overlap
- edge light
- scale
- blur as distance
- restrained directional shadows
- grain/texture where appropriate

Do not use neon glow as a substitute for hierarchy.

## Motion
- Prefer transform and opacity.
- Batch scroll reads/writes in requestAnimationFrame.
- Do not animate width/height/top/left unless necessary.
- Motion needs a narrative reason.
- Build reduced-motion states intentionally.

## Mobile
- Design separate crop/composition when needed.
- Increase tap targets.
- Reduce media payload.
- Avoid tiny overlay copy on video.
- Cap real-time 3D DPR and geometry complexity.

## Common machine-made signals to avoid
- same six sections every project;
- repeated equal cards with identical icons;
- fake stats and fake dashboards;
- centered headline + centered paragraph in every act;
- gradient text;
- generic purple/blue neon;
- decorative numbering that communicates nothing;
- unnecessary “scroll to explore” cues.
